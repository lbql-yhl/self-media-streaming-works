# 产品需求文档 - Velon 美食目的地企划本

## 产品概述

### 产品名称
Velon

### 一句话定位
面向美食优先型旅行者的本地企划本：按口味找城与店，编排探店动线，用多草稿对比定稿——不是景点打卡 App。

### 产品简介
Velon 专为国外用户设计。旅行以探店觅食为主时，用户先选定口味偏好，再获得城市与店铺建议，把候选店排成少绕路的一日/多日动线，并维护踩坑备注与行程草稿。

- **面向**：美食优先型旅行者（Trip 以吃为主，景点为辅或不去）
- **核心闭环**：口味偏好 → 推荐城/店 → 动线编排 → 探店收官册（Digest）
- **不做**：景点导览、社交 Feed、实时地图导航、在线订座

### 内容边界（避免空壳）
- 内置精选美食城市（建议首发 6–8 座，如 Tokyo / Seoul / Bangkok / Taipei / Paris / New York / Mexico City / Istanbul，可增减但须有实质店铺数据）
- 每城至少若干可规划店铺（本地静态图文），含口味标签、大致片区、排队/休息等踩坑字段
- 全部内容本地打包，路径 `assets/images`；无网络依赖、无 `.env`

### App Store 差异化（降低 4.2 / 4.3 风险）
| 维度 | Velon 做法 | 避免做成 |
|------|------------|----------|
| 主体 | 美食优先旅行者的「行前企划」 | 泛旅行攻略 / 餐厅点评站 |
| 主交互 | 口味筛选驱动推荐；动线排序；草稿并排对比 | 城市列表 → 店铺列表 → 收藏 |
| 功能骨架 | 偏好→推荐→路线→对比定稿 | 仅笔记 / 仅收藏清单 |
| 内容 | 有限精选城+店的可编排数据包 | 空模板或极薄占位内容 |

## 功能需求

### 主链路（P0，必须完整可用）
1. **口味偏好**：酸辣、烘焙、在地小吃、小众老店等标签多选；作为推荐与筛选的真相源
2. **城/店推荐**：按偏好匹配城市与店铺，展示匹配理由（标签命中），支持进入详情
3. **探店动线编排**：将候选店排入日程；按片区/顺序减少来回折返；支持调整顺序与日程日
4. **踩坑备注**：店铺级排队、休息日、推荐时段等备注，编排时可参考
5. **探店收官册（Digest）**：将 Visit Notes 与实拍汇总为本城美食小结画册，支持预览与分享图片卡

### 增强（P1，主链路完成后再做）
6. **心愿店铺清单**：收藏待访店，可一键加入某草稿
7. **探店记录**：行程结束后绑定实拍与口味笔记，留存在本地

### 内购
- 需要独立内购页（虚拟货币/金币消耗类入口即可）
- **不需要**会员订阅解锁功能

## 信息架构

### 一级 Tab（3–4 个 + Profile）
建议：

| Tab | 职责 |
|-----|------|
| Discover | 偏好入口 + 城/店推荐浏览 |
| Routes | 当前/草稿行程与动线编排 |
| Digest | 探店收官册：选行程 → 生成 Visit Notes / 实拍画册预览并分享 |
| Profile / Settings | 偏好管理、协议、内购入口等 |

至少 3–4 个一级页面；必须包含 Setting/Profile 页。

### 二级页面（2–4 个，从 Tab 进入，不展示 TabBar）
- 城市详情（该城推荐店与标签）
- 店铺详情（踩坑备注、加入路线/心愿）
- 动线编辑（排序、分日）
- 草稿对比详情 / 探店记录编辑（按实现取舍）

### 导航规则
- TabBar **仅**在一级 Tab 展示；所有子页面隐藏 TabBar

## 视觉与主题

### 主题色
- 主色系：`#e87b7b`（珊瑚粉，食欲与温暖）
- 必须集中在主题色文件管理；业务 UI 禁止散落写死无关色

### 配套中性色（避免整 App 过粉）
| Token 建议 | 用途 | 参考 |
|------------|------|------|
| Charcoal | 主文字、导航 | `#2C2A29` 或近黑暖灰 |
| Warm Stone | 次级文字、分割 | `#8A817C` |
| Cream Surface | 页面底、卡片底 | `#F7F1EE` |
| Deep Accent | 强调按钮/选中态（可与主色搭配） | 主色加深一档或暖棕 `#5C4033` |

有层次与质感；触控热区约 44×44 pt。无特殊说明使用系统默认字体。

## 工程与交付约束

### 文件结构
必须有：`assets/images` 目录；图片全部本地引用该路径。

### 技术要求
- 最低 iOS 15.0；原生 UIKit / Swift
- 颜色走主题文件；英文 UI 全文案（源码注释可用中文）
- 输入页支持点击空白收起键盘
- 错误提示仅友好英文，不展示底层异常原文
- 不需要 `.env` 管理环境
- 应用内需内购页，但不做会员解锁

### 整体结构示意
```

  Discover --> CityDetail
  Discover --> SpotDetail
  Routes --> RouteEditor
```
